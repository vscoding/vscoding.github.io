EMQX

EMQX 是面向 MQTT 的消息代理。本示例部署一个单节点实例，并持久化运行数据和日志。

准备目录

mkdir -p data log

确保容器对这两个目录具有写入权限。

Docker Compose 配置

创建 docker-compose.yml：

services: emqx: image: emqx/emqx container_name: emqx restart: unless-stopped ports: - "1883:1883" - "8883:8883" - "8083:8083" - "8084:8084" - "18083:18083" volumes: - "./data:/opt/emqx/data" - "./log:/opt/emqx/log"

启动与验证

docker compose config docker compose up -d docker compose ps docker compose logs -f emqx

服务启动后，通过 http://<服务器地址>:18083/ 访问 Dashboard。

端口说明

端口

用途

1883

MQTT over TCP

8883

MQTT over TLS

8083

MQTT over WebSocket

8084

MQTT over secure WebSocket

18083

Dashboard 和 REST API

注意事项

  • 首次登录后应立即修改默认管理员密码。

  • 8883 和 8084 只有在正确配置 TLS 后才能提供加密连接。

  • 生产环境建议固定镜像版本，避免 latest 指向的新版本带来非预期升级。
