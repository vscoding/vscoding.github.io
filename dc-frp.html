FRP

FRP 用于将内网服务安全地暴露到具有公网入口的服务器。本示例分别部署 FRP Server（frps ）和 FRP Client（frpc）。

FRP Server

Docker Compose 配置

创建 docker-compose.yml：

services: frp-server: image: registry.cn-shanghai.aliyuncs.com/iproute/frp:0.61.0 container_name: frp-server network_mode: host restart: always environment: TZ: Asia/Shanghai volumes: - "./server.toml:/opt/frp/server.toml:ro" - "./log:/opt/frp/log" working_dir: /opt/frp command: - ./frps - -c - server.toml

Server 配置

创建 server.toml：

bindPort = 7000 log.to = "./log/frps.log" log.level = "info" log.maxDays = 3 auth.method = "token" auth.token = "replace-with-a-random-shared-token" webServer.addr = "0.0.0.0" webServer.port = 7500 webServer.user = "admin" webServer.password = "replace-with-a-strong-password"

webServer.addr = "0.0.0.0" 会对外监听 Dashboard。若不需要远程访问，应改为 127.0.0.1 ；对外开放时必须通过防火墙限制来源并更换示例凭据。

启动与验证

docker compose config docker compose up -d docker compose ps docker compose logs -f frp-server

FRP Client

Docker Compose 配置

创建 docker-compose.yml：

services: frp-client: image: registry.cn-shanghai.aliyuncs.com/iproute/frp:0.61.0 container_name: frp-client network_mode: host restart: always environment: TZ: Asia/Shanghai volumes: - "./client.toml:/opt/frp/client.toml:ro" - "./log:/opt/frp/log" working_dir: /opt/frp command: - ./frpc - -c - client.toml

Client 配置

创建 client.toml ，将 serverAddr 替换为 FRP Server 的实际地址：

serverAddr = "127.0.0.1" serverPort = 7000 log.to = "./log/frpc.log" log.level = "info" log.maxDays = 3 auth.method = "token" auth.token = "replace-with-a-random-shared-token" [[proxies]] name = "ssh" type = "tcp" localIP = "127.0.0.1" localPort = 22 remotePort = 6000

Client 与 Server 的 auth.token 必须完全一致。示例将客户端主机的 SSH 端口映射到 FRP Server 的 6000 端口。

启动与验证

docker compose config docker compose up -d docker compose ps docker compose logs -f frp-client
