Gitea

Gitea 是轻量级 Git 仓库与协作平台。本示例使用内置 SQLite 数据库，适合单机部署。

准备数据目录

容器使用 UID 和 GID 1000 写入数据目录：

mkdir -p data sudo chown -R 1000:1000 data

如果主机使用其他用户运行服务，应同步调整目录所有者以及 Compose 中的 USER_UID、 USER_GID。

Docker Compose 配置

创建 docker-compose.yml：

services: server: image: gitea/gitea container_name: gitea restart: always environment: USER_UID: "1000" USER_GID: "1000" GITEA__server__SSH_PORT: "2222" GITEA__service__DISABLE_REGISTRATION: "true" volumes: - "./data:/data" - "/etc/timezone:/etc/timezone:ro" - "/etc/localtime:/etc/localtime:ro" ports: - "3000:3000" - "2222:22"

GITEA__server__SSH_PORT 控制页面中展示的 SSH 克隆端口；容器仍监听内部端口 22。

启动与初始化

docker compose config docker compose up -d docker compose ps docker compose logs -f server

打开 http://<服务器地址>:3000/ 完成首次初始化，并在安装页面创建管理员账户。当前配置关闭普通用户自行注册，后续用户由管理员创建。

SSH 克隆地址使用宿主机端口 2222 。部署在反向代理后时，还应根据实际域名配置 Gitea 的 ROOT_URL、 DOMAIN 和 SSH_DOMAIN。

注意事项

  • /data 包含仓库、配置和默认 SQLite 数据库，应纳入备份。

  • 对外开放 SSH 前，应在防火墙中限制不必要的来源。

  • 生产环境建议固定 Gitea 镜像版本，并在升级前备份数据。
