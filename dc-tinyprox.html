Tinyproxy

Tinyproxy 是轻量级 HTTP/HTTPS 代理服务。本示例保留现有镜像和 ANY 访问控制参数，但默认只把代理端口绑定到宿主机回环地址。

Docker Compose 配置

创建 docker-compose.yml：

services: tinyproxy: image: dannydirect/tinyproxy:latest container_name: tinyproxy restart: always ports: - "127.0.0.1:8888:8888" command: - ANY

ANY 表示 Tinyproxy 接受任意来源地址。由于端口只绑定到 127.0.0.1 ，默认仅允许宿主机本地连接。

如果需要为局域网提供代理，应将端口绑定地址改为宿主机的指定内网 IP，并把 ANY 替换为允许访问的 IP 或 CIDR。例如：

ports: - "192.168.1.10:8888:8888" command: - "192.168.1.0/24"

启动与验证

docker compose config docker compose up -d docker compose ps docker compose logs -f tinyproxy

本机可以使用 curl 验证代理：

curl --proxy http://127.0.0.1:8888 https://example.com

安全说明

不要将使用 ANY 的代理直接暴露到公网。开放代理可能被用于匿名转发、扫描或攻击，并产生额外流量和法律风险。

当前 dannydirect/tinyproxy 镜像已被维护者标记为 deprecated。本文为保持现有部署兼容性未替换镜像；新部署应先评估维护者推荐的替代镜像并固定版本。
