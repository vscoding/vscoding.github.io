Docker Compose

本专题收录常用基础服务的单机 Docker Compose 部署示例。每个子主题都包含可直接调整的配置、启动命令和必要的安全说明。

使用说明

示例默认使用 Docker Compose v2，并以 docker-compose.yml 作为配置文件名。部署前应先根据实际环境调整镜像、端口、主机地址和凭据，然后检查最终配置：

docker compose config docker compose up -d docker compose ps

排查服务问题时可以查看日志：

docker compose logs -f
