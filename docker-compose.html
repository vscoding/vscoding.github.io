使用说明

示例默认使用 Docker Compose v2，并以 docker-compose.yml 作为配置文件名。部署前应先根据实际环境调整镜像、端口、主机地址和凭据，然后检查最终配置：

docker compose config docker compose up -d docker compose ps

排查服务问题时可以查看日志：

docker compose logs -f

通用约定

  • 示例中的相对路径均以 docker-compose.yml 所在目录为基准。

  • 包含密码、令牌等敏感信息时，优先通过 .env 注入，并将该文件加入 .gitignore。

  • 对外开放端口前应配置主机防火墙；管理页面建议置于 HTTPS 反向代理之后。

  • 生产环境应固定镜像版本，并在升级前备份持久化目录。

  • network_mode: host 仅适用于 Linux 主机，并会绕过 Compose 的端口映射。
